# Actividades Python - UTN

Aquí voy a subir las actividades de Python de la UTN propuestas.

## Materia

Programación IV - Cuarto Cuatrimestre

## Entorno

El entorno virtual (`.venv/`) no se versiona. Para recrearlo:

```bash
python -m venv .venv
```

Activarlo (Windows PowerShell):

```bash
.venv\Scripts\Activate.ps1
```

Instalar dependencias:

```bash
pip install -r requirements.txt
```
